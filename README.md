# 🎂 A Birthday Transmission

> A little corner of the internet, built to celebrate someone extraordinary.

**A Birthday Transmission** is a personalized, interactive birthday experience created for Chidinma by Veekaay. More than a traditional birthday card, it turns a heartfelt message into a digital experience, combining thoughtful words, personal memories, photography, video, and a bold visual aesthetic.

The project is a reminder that sometimes the best gifts aren't things you can wrap. Sometimes, they're things someone creates just for you. ❤️

## ✨ Features

- **Personalized Landing Page:** A bold introduction with a futuristic, dark-themed aesthetic and warm orange accents.
- **Interactive Birthday Letter:** A dedicated birthday message revealed through an interactive button.
- **Personal Photo Gallery:** A collection of memorable moments, complete with captions.
- **Video Playback:** Embedded video moments that visitors can play directly on the page.
- **Image Lightbox:** Click photographs to view them in an enlarged presentation.
- **Responsive Design:** Designed to work across desktop and mobile screens.
- **Subtle Animations:** Smooth transitions and visual effects that make the experience feel alive.
- **Accessibility Considerations:** Includes reduced-motion support for visitors who prefer fewer animations.

## 🎨 Design & Aesthetic

The experience uses a combination of:

- Deep black backgrounds.
- Warm orange and cream accents.
- DM Mono and Manrope typography.
- Grid-inspired backgrounds.
- Futuristic orbital visual elements.
- Smooth transitions and layered photographic elements.

The overall direction is minimal, expressive, personal, and futuristic.

## 🛠️ Built With
